# MemorizeMe Asset Directory 🎨🖼️

This directory contains visual brand assets, logos, icons, and media used throughout the project and its documentation.

---

## 📁 Directory Structure

```text
assets/
├── branding/
│   ├── logo.svg               # Full horizontal vector logo
│   └── favicon.svg            # Square app icon & favicon
└── docs/
    ├── screenshots/           # UI screenshots and mobile mockups for README
    └── diagrams/              # Exported architecture diagrams (PNG, SVG)
```

---
